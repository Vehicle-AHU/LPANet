# Weights and semantic embeddings

Place released LPANet checkpoints and the class-semantic embedding file in this directory, for example:

```text
weights/
├── yolov5l.pt
└── class_description_embedding_mpnet.pkl
```

The trained weights and corresponding test results are available at:

https://pan.baidu.com/s/1IJ3_-cgXo3Esvyge4OWHJA?pwd=drn5

The semantic embedding rows must follow the class order in `data/DroneVehicle_poly.yaml`.
